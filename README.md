# BuzzTimer

Jogo Unity para 2 a 4 jogadores com comandos sem fios Buzz! da PS3.

## Regras

- Cada ronda apresenta um tempo-alvo entre 3 e 10 segundos.
- O botão verde inicia ou continua o cronómetro oculto.
- O botão vermelho para o cronómetro e passa a vez.
- Antes de continuar, o jogador seguinte pode usar o botão amarelo para desafiar o anterior.
- Se o tempo acumulado ultrapassou o alvo, o jogador anterior é eliminado.
- Se o tempo ainda não ultrapassou o alvo, incluindo quando é exatamente igual, o desafiante é eliminado.
- A ronda seguinte começa no jogador seguinte ao eliminado.
- Ganha o último jogador em jogo.

Não é necessário ter quatro jogadores. A partida terá sempre `número de jogadores - 1` rondas.

## Executar

Liga o recetor Wbuzz e executa `Builds/Windows/BuzzTimer.exe`.

Para recompilar, abre o projeto no Unity 6000.3.22f1 e usa **Buzz Timer > Build Windows**.
